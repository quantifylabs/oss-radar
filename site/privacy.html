Privacy and analytics

Analytics are disabled by default. When an operator explicitly configures an aggregate event endpoint, OSS.Radar sends only a success-event name. It never sends repository names or URLs, searches, filter values, comparison contents, IP-derived identifiers, cookies, or persistent user identifiers.

The possible events are: repository opened, feed subscribed, filters applied, comparison created, share URL copied, and label feedback opened. Repository browsing is counted only as an undifferentiated total; it is not tied to a repository.

The destination and retention policy of an enabled deployment must be disclosed here by its operator. This deployment has no analytics endpoint configured.
